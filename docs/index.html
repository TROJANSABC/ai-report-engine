关键设计决策

三个让产品真正有用的选择

DECISION 01

模板系统

不做「一段描述生成一篇文章」，而是预置周报 / 日报 / 趋势简报等结构，选定模板后由 AI 按章节填充。Jinja2 驱动，结构即产品。

DECISION 02

多源交叉验证

对关键数据点自动比对多个来源，输出一致性说明与置信度：3 个来源一致 还是 来源A=X，来源B=Y。

DECISION 03

引用溯源

每条信息附原文链接，用户可点击验证。既提升可信度，也从机制上缓解大模型的幻觉问题。

本地运行

# 1. 克隆
git clone https://github.com/TROJANSABC/ai-report-engine.git
cd ai-report-engine

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置并启动
cp .env.example .env   # 填入 TAVILY_API_KEY / OPENAI_API_KEY
streamlit run app.py
